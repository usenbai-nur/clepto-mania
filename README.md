# CLEPTO MANIA

A 2D top-down stealth game developed in Unity URP where the player takes the role of a thief collecting valuable items while avoiding patrol NPCs and completing levels.

## Game Overview

In CLEPTO MANIA, the player explores different environments, steals valuables, fills the money bag, and avoids guards patrolling the map. The objective is to collect all required treasures and escape without getting caught.

The game includes:

- Multiple game scenes
- Stealth gameplay mechanics
- Patrol NPC system
- Win/Lose conditions
- Main Menu
- Pause system
- Level progression
- Visual effects and audio

---

## Features

### Gameplay
- Collect jewelry and valuable items
- Fill the bag progress system
- Avoid enemy NPC patrols
- Detection and lose conditions
- Complete levels to progress

### Systems
- Main Menu scene
- Pause Menu (ESC)
- Return to Main Menu
- Win screen
- Lose screen
- Scene management system

### Visual Effects
- Coin particle effects
- UI feedback
- Animated money bag progress
